## Overview:
Modern Machine Learning is shaped by the hardware used under the hood. It ranges from role-specific hardware such as NPU(Neural Processing Unit), LPU(Language Processing Unit), DPU(Data Processing Unit) to Core ML processors such as CPU, TPU and GPU. CPU, the brain of the computer is present in all the computers, primarily focused on the processing complex tasks. On the other hand GPU, are known for performing multiple small tasks parallely in order to accomplish a task much faster than a CPU could ever do. ML models are repeatedly trained on huge datasets, so that they recognise the pattern hidden under the data. Model training can last from minutes to days, based on the size of the model and the dataset. Hence, GPU programming can help in improvising model training and save time. This was my motivation behind learning GPU Programming. This article, is my exploration on GPU programming so far, the challenges, learnings and key takeaways.

## CPU vs GPU
CPU - Central Processing Unit is a part of all the computers, as mentioned earlier. They consists of Control Unit(CU) to understand what operation is required. Arithmetic Logic Unit(ALU) to handle mathematical and logical operations. Registers, the high-speed, low-capacity storage cells located directly on the CPU chip used to hold temporary data and instructions during execution.\
![CPU Architectural Diagram]({{'assets/images/cpu_architectural_diagram.jpg'|relative_url}})\
Due to this arrangement, CPUs are better at performing complex single task at a time. For executing multiple tasks at a time, CPU uses context switching to achieve concurrency[(ref)](https://www.youtube.com/watch?v=RlM9AfWf1WU). In order to achieve parallel programming, there needs to be multiple CPU cores stacked together, performing one task each. This is where GPUs work differently and can run multiple tasks at a time. \
GPU - Graphical Processing unit accelerates tasks like rendering of images, animations etc by performing massive number of computations in parallel. GPU contain Processing Cores, which intern contains several Graphics Processing Clusters(GPC). Each GPC has several Streaming Multiprocessors(SM). Each SM contains serveral warps and ray tracing cores. Each warp contains several CUDA shaded cores and tensor core. CUDA cores are used for binary calculation, consisting of arthimatic operators. Tensor Cores are the matrix multiplication and addition calculators.Ray Tracing cores are for executing ray tracing algorithms used in graphic designing[(ref)](https://www.youtube.com/watch?v=h9Z4oGN89MU).\
